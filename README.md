# Barbearia do Gazão — Landing page

Landing page responsiva em HTML, CSS e JavaScript puro, sem frameworks.

## Como executar
1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. É necessária conexão à internet para carregar as fontes e imagens externas.

## Como funciona o agendamento
O formulário valida os campos obrigatórios e abre o WhatsApp com uma mensagem preenchida. O agendamento não é confirmado automaticamente; a barbearia deve responder confirmando a disponibilidade.

## Antes de publicar
- Atualize nomes, fotos e especialidades ilustrativas dos barbeiros.
- Confirme se o endereço está correto no mapa do Google.
- Atualize o horário de funcionamento no objeto `BARBEARIA` do arquivo `script.js`.
- Substitua as fotos de exemplo por imagens autorizadas da própria barbearia.
